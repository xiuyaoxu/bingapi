功能一览

本接口提供以下全部能力，所有接口均支持跨域（CORS）调用，并支持 mkt / res / idx 等通用参数。

/api · 元数据
返回今日（或指定 idx 天数前）图片的 JSON 元数据：标题、版权、日期、图片地址等。
/api/image · 直接出图
直接 302 跳转到 Bing 源图地址（不缓存、不代理，由 Bing 直接提供图片）。
/api/list · 历史列表
返回最近 n（1–8）天图片的 JSON 列表，配合 idx 可翻页查看更早的图片。
/api/random · 随机一张
从最近 8 天中随机返回一张图片的 JSON 元数据，适合做每日一图 / 背景。
/health · 健康检查
返回 {"status":"ok","ts":...}，用于监控与心跳检测。
/ · 首页
即本页面，实时调用上方接口进行交互展示。

通用参数

参数说明可选值 / 范围
mkt地区市场zh-CN、en-US、en-GB、ja-JP、de-DE、fr-FR …
res图片分辨率1920x1080、1366x768、UHD（4K）
idx往前天数（0=今天）0–7
n列表数量（仅 /api/list）1–8

网页直接调用代码

把示例中的 https://你的域名 换成你的接口地址（如 https://bing.aoran.bid）即可直接使用；点击每段右上角「复制」可拷贝代码。

1. 一行嵌入今日图片（默认跳源图）

<img src="https://你的域名/api/image" alt="Bing 每日图片" />

2. JavaScript 获取今日元数据

fetch('https://你的域名/api')
  .then(r => r.json())
  .then(d => {
    console.log(d.title, d.copyright);
    document.querySelector('img').src = d.url;
  });

3. 获取最近列表（JSON）

fetch('https://你的域名/api/list?n=7')
  .then(r => r.json())
  .then(d => console.log(d.images));

4. 随机一张并跳转源图

fetch('https://你的域名/api/random')
  .then(r => r.json())
  .then(d => { location.href = d.url; }); // 或 image.src = d.url
